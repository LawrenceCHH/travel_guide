# checklist｜個資外洩掃描（`scrub_check.py` 的 md 後備）

> 無 Python 3 執行環境時使用本檔。commit（或分享）任何檔案給版控前，**必須先跑完本檢查**（見 `references/privacy.md` 與 `references/progress_protocol.md` 的 commit 前置條件）。

## 目標
從 `trips/{trip}/private/` 下的原始輸入（任何格式：md/txt/貼上的訂房確認信/截圖轉文字等）手動抽出 8 類 token，
逐一在**待版控檔案**（`trip_context.json`、`progress.md`、`materials/*.json`、`plan/*.md`）中搜尋這些字串，
命中即為外洩，必須先修正（刪除或改為抽象化描述，依 `references/privacy.md` 的規則表）才能繼續。

## 必查的 8 類 token

1. **訂房確認號／訂單編號**（如 8 位數字、英數混合的 confirmation code）
2. **訂房人姓名**（含所有同行者姓名，不只主要訂房人）
3. **航班號**（去程/回程，如 `BR225`、`CI702`、`7C2703` 這類航空公司代碼＋數字格式）
4. **飯店/住宿全名**（注意：允許保留「區域＋最近車站」，但不可出現具體飯店名稱或民宿名稱）
5. **電話號碼**（含國際冠碼、市話、手機，任何格式的數字串）
6. **Email 地址**
7. **護照號碼**
8. **門牌地址**（具體街道門牌號，不可出現；區域層級描述可保留）

## 執行步驟

1. 打開 `private/input/` 下所有原始輸入檔，逐份通讀一次，把上述 8 類實際出現的值抄到一張暫存清單上（此清單本身不得進版控，用完即丟）。
2. 針對每一個待版控檔案（`trip_context.json`、`progress.md`、`materials/spots.json`、`materials/food.json`、`plan/*.md`），用文字搜尋（Ctrl+F / grep）逐一查找暫存清單上的每個值。
3. 任何一個值在待版控檔案中被找到 → 記錄「檔名:行號 含 X 類 token『值』」，視為違規。
4. 全部檔案、全部 token 都查過一輪後，彙總違規清單。
5. **只要清單非空，本次不得 commit / 分享**，須先修正該檔案內容（依 `references/privacy.md` 的去識別化規則表，例如飯店名改為「區域＋最近車站」），再重跑一次步驟 2~4，直到清單為空。

## 提醒
- `derived_constraints`（如「Day1 05:00 抵達為紅眼班機」）這類**推論結果**是允許保留的自然語言，不是個資，不要誤判為需要刪除的內容——只有 8 類清單本身的原始值才需要清除。
- `private/` 目錄本身不需要被掃描（它本來就不進版控），只掃描**即將進版控**的檔案。
