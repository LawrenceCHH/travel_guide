# 11｜緊急應變

> **風險分級：最嚴格等級**（見 `references/research_rules.md` §7）。只採官方第一手來源，每條資訊後綴來源連結，不接受概括引用。
> 「出事沒人能負責」——本主題優先度最高，即使整體採平行模式，也不得因排程壓縮而簡化。

## 目的
整理當地緊急求助管道、駐外館處、可英文/中文就醫的醫院，以及證件/財物遺失的補辦流程，讓使用者在意外發生當下知道第一時間該找誰。

## 前置依賴
- `trip_context.json`：`destination`、`stay`（區位，用於挑選鄰近醫院）
- 無前序主題依賴，但**建議與 02/03 同批完成**（同屬最嚴格等級，檢索邏輯類似）

## 必須產出的章節與表格欄位

### 1. 報警/消防/救護熱線
| 用途 | 電話號碼 | 備註 |
|---|---|---|
| 報警 | | |
| 消防 | | |
| 救護車 | | |

- 若當地為單一號碼（如某些國家報警/救護共用一線），需明確說明。

### 2. 駐外館處
- 我國駐當地代表處/辦事處的電話（含急難救助專線，通常另有 24 小時號碼）、地址、服務時間。
- 來源必須是外交部領事事務局或駐外館處官網。

### 3. 可英文或中文就醫的醫院
| 醫院名稱 | 地址 | 距住宿區域車程 | 是否有英文/中文服務 | 電話 |
|---|---|---|---|---|

- 優先挑選鄰近 `trip_context.stay.area` 的醫院，至少 1~2 家。

### 4. 護照遺失補辦
- 當地報案（取得警方報案證明）→ 向駐外館處申請補發或臨時入國證明書的完整流程與所需文件。

### 5. 信用卡掛失
- 常見發卡銀行的海外掛失專線查詢方式（提醒使用者出發前記下自己卡片的海外掛失號碼，因為此為通用流程說明而非個人卡片資訊）。

## 必須回答的問題清單
- 在當地發生緊急狀況，打哪支電話？
- 我國駐當地代表處在哪裡？急難救助電話是多少？
- 如果生病，哪家醫院可以用英文或中文溝通？
- 護照掉了要怎麼辦？
- 信用卡不見了要打去哪裡掛失？

## 檢索指引與來源要求
- 全部依 `references/research_rules.md` §7 最嚴格等級：熱線號碼、駐外館處資訊、護照補辦流程一律採 `tier: official`（外交部領事事務局、駐外館處官網、當地政府緊急服務頁面）。
- 醫院是否支援英文/中文服務，若官方未明確標示，可輔以 `tier: blogger`/`tier: platform`（如國際旅遊醫療平台）佐證，但需明確標示為輔助來源。

## 完成判準 checklist
- [ ] 報警/消防/救護三線電話齊全（或說明合一號碼）
- [ ] 駐外館處含急難救助專線與地址
- [ ] 至少 1~2 家鄰近住宿區的英文/中文就醫醫院
- [ ] 護照遺失補辦流程完整
- [ ] 信用卡掛失查詢方式已說明
- [ ] 所有號碼與地址皆有 `tier: official` 來源

## 常見錯誤
- 醫院清單挑選離住宿區太遠的知名大醫院，忽略「就近」這個緊急情境下的關鍵條件。
- 駐外館處只寫代表處電話，漏掉專門的急難救助專線（兩者常不同號）。
- 護照補辦流程直接照抄台灣一般護照申辦流程，沒有區分「海外遺失」的特殊路徑。
