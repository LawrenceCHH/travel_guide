# 旅程問卷（選填）

> 這份問卷**不是必填**。每一題後面都寫了「不回答會怎樣」，可以只填您在意的部分，其餘交給 agent 判斷。

## A. 決定性資訊（最影響規劃品質，建議優先填）

**A1. 目的地（國家／城市）**
- 答：
- 不回答會怎樣：**唯一硬停欄位**。抽不到目的地，流程會直接中止並反問，無法用預設值帶過。

**A2. 旅遊起訖日期**
- 答：
- 不回答會怎樣：agent 會反問。日期影響季節判定、資訊時效性判斷、天數，沒有合理預設可用。

**A3. 出發／回程班機時刻與機場航廈**
- 答（去程日期/時刻/機場航廈、回程日期/時刻/機場航廈）：
- 不回答會怎樣：agent 會推斷該航線常見班次時刻，並在 `progress.md` 標記待覆核。會直接影響首尾半天的 buffer 計算，建議盡量填寫實際時刻。

**A4. 航空公司**
- 答：
- 不回答會怎樣：agent 會推斷該航線主流航司，標記待覆核。影響行李規範查詢的準確度。

**A5. 住宿區位（不需門牌，區域即可，如「XX 車站附近」）**
- 答：
- 不回答會怎樣：agent 會推斷該目的地常見住宿區，標記待覆核。影響景點分區與行程動線安排。

## B. 成員結構

**B1. 同行人數與組成（成人/孩童/長輩、是否需輪椅或推車）**
- 答：
- 不回答會怎樣：預設為「一般成人旅客」，仍會產出同伴友善度評分，但不做無障礙或親子的特殊加權。

## C. 偏好（全部留空即走通用預設，不影響流程）

**C1. 已經確定要去的景點／店家（指名必去清單）**
- 答：
- 不回答會怎樣：3 套行程方案完全由 agent 依素材庫與熱門度組合，不受既定指名點的約束。

**C2. 行程風格傾向（可複選：經典必去／深度在地／輕鬆慢遊，或都想看看）**
- 答：
- 不回答會怎樣：三套方案照預設三軸各自產出（經典必去 / 深度在地 / 輕鬆慢遊），不特別偏重某一軸。

**C3. 美食偏好或忌口**
- 答：
- 不回答會怎樣：素材庫依通用類別覆蓋規則挑選，不特別排除或加權任何類別。

**C4. 預算等級（節省／中等／寬裕）**
- 答：
- 不回答會怎樣：素材與行程不特別依預算篩選，但會在花費估算中維持中等等級的假設。

**C5. 慣用電信商（影響漫遊/eSIM 方案比較的切入點）**
- 答：
- 不回答會怎樣：04 網路與漫遊會列出所有主流方案（eSIM／實體 SIM／WiFi 分享器／電信商漫遊）做通用比較，不特別對應某電信商的優惠。

**C6. 資訊來源偏好（例如偏好官方公告、或偏好部落客實測心得）**
- 答：
- 不回答會怎樣：依各主題預設的來源分級策略（官方優先或部落客優先，視主題風險等級而定），不特別偏重單一來源類型。

**填完後怎麼用**：把這份檔案交給 agent，或直接把答案貼進對話。agent 會把這裡的內容連同其他既有輸入一起抽取進 `trip_context.json`（見 `references/privacy.md`），原始問卷本身留在 `private/`，不進版控。
