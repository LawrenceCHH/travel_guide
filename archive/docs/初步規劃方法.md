#### skill 新架構
- 文件都是 md 檔，內容為核心，所有的呈現方式都依照 md 再設計成網頁或其他形式
- 初始使用，由 agent 上網整理最新、最實用的資訊 
  - 建立通用旅遊知識文件 (更新頻率較少)
    - 衣物準備，各旅遊氣候情境應該準備怎樣的衣物? 例如: 冬季，該地區有暖氣，可能適合洋蔥式穿法，用表格呈現方便判斷
    - 旅遊物品，轉接頭、行動電源、保養品、信用卡...等等你建議的項目，表格分類呈現，說明欄註記為什麼要帶這個? 有什麼用途
    - 行前準備的 check list (除了物品準備、還涵蓋訂機票、旅館...等資訊查詢)
  - 建立旅遊行程文件 (更新頻率高)，各主題獨立一個 md 檔案，十分強調近一年的最新資訊，真的沒有就近兩年，而且務必引用來源網址，避免AI幻覺
    - 使用者提供一個檔案讓 agent 閱讀，內容包含 (機票、住宿、成員概述、成員喜好、期望的旅遊風格等等)，我覺得有個範例模板 md ，裡面條列問題讓使用者填寫就好，也要註記如果不填寫就讓 agent自行推斷，不會讓整個流程中斷
    - 機場通關
      - 稍微固定流程，但各地通關可能不一樣，建議收集最新的台灣部落客網站資訊，台灣人才懂台灣人困境；主要要把讀者當沒出過國的人，文字不需要太多，但通關流程必須精簡、精準，照著步驟執行一定會通關的細緻程度；違禁品項目很重要；行李規範會依據使用者提供的檔案內容上網找最新資料；快速通關方法、通關注意事項每個國家不同，也會有不同的規則，例如日本好像可以事前填表單，韓國也是，這些都要最新資訊；另外，這個項目需要確切網址來源，讓每個段落都有所對應，不然agent 會亂產生內容，出事的話沒人能負責
    - 保險資訊
      - 依據成員提供的檔案，上網找推薦的保險資訊，來源可分為官方、部落客推薦。這個項目需要確切網址來源，讓每個段落都有所對應，不然agent 會亂產生內容，出事的話沒人能負責
    - 交通資訊
      - 落地後有哪些交通方式可到達下個目的地? 部落客都推薦哪些方式
      - 當地是否有交通卡? 申辦步驟、儲值、相關注意事項，例如: 日本西瓜卡、韓國 Toss 卡...
      - 行程間的交通方式有哪些? 有地鐵嗎? 日本有電車、歐美有火車...等等
      - 計程車，注意事項是什麼、怎麼防止被詐騙?
      - 建議哪些交通相關的APP 或 網站
      - 有來源網址佐證
    - 支付方式
      - 若去當地的話，自助旅行都用哪些支付方式?
      - 台灣部落客怎麼說?
      - 怎麼辦理或使用這些支付方式? 申辦流程步驟精簡且清晰
      - 不同支付方式優缺點比較，會不會有哪些是比較傾向當地人而非遊客，都要表格呈現
      - 有來源網址佐證
    - 當地習慣
      - 上網找看看當地是否有些習俗，例如: 靠右通行、穿拖鞋不正式、飲食習慣偏好呢、生活習慣、購物習慣、外國遊客到當地需要注意哪些事情，例如: 用泰語買東西價格低，英文的話價格會翻倍
    - 美食景點資訊 (建議json or yaml，這些都是原始素材，用於組合成)
      - 核心，且是最常更動的檔案
      - 主要重點預留出發、回程的時間，避免影響班機
      - 使用者一定要給出發、回程時間地點資訊，這樣agent才有初步資訊可以發想或照使用者資訊規劃；建議再補住宿資訊，可以適時安排附近景點
      - 景點規劃，使用者應該要提供一份文件描述大概想去哪裡，中間一定會有空白、不清楚的地點，這時候agent 應該要主動上網搜尋最新當地旅遊景點資訊，除了熱門景點(只去當地的話一生一次有哪些景點必去)，還要有當地人推薦的私房觀光景點，才可以深入探索當地，景點要附推薦理由；沒有提供就是照部落客推薦的行程優先安排，有實際體驗較不容易出錯
      - 美食規劃，要從前一區塊的景點去找資料，分兩塊，照景點區塊建議熱門美食 (觀光客/當地人)；照實際景點步行距離可以到的熱門美食 (觀光客/當地人)，推薦種類應該要多樣化，且觀光客與當地人的喜好美食應該各3種，附上推薦理由簡述
    - 行程安排
      - 這份文件必須要有旅遊計畫，才能依照該文件的景點、美食資訊推導整個過程
      - 旅行風格，喜歡寬鬆自在、還是行程緊湊，喜歡自然景觀、還是打卡網美景點；沒有提供就是照部落客推薦的行程優先安排
      - 主要目的是依據素材，提供多樣化的組合選擇給讀者參考
      - 景點可能會很多，但可以從過往部落客推薦的景點文章，把相關的景點拉出來成為一個行程。
      - 建議以半天為區塊去規劃，不列具體時間，只要上午或下午就好，但半天區間的景點、美食距離必須相近；天與天之間的景點距離可以稍微拉遠一些
      - 依據現有的景點素材，規畫三種多樣化的行程安排
      - 景點會依照大區域分類，大區域簡述、大區域的美食推薦、大區域的景點、景點附近美食推薦 (建議步行可到)
