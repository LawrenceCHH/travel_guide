## 首尾 Buffer（引用 `plan/01_flight_stay.md` 已算出的數值）

**Day1（10/17）落地：**
```
落地時刻：05:00（ICN T2）
+ 入境通關/行李提領/機場出關：約60分鐘 → 06:00出關
+ 機場到市區交通（AREX直通車+轉乘）：約60-75分鐘 → 07:00-07:15抵達市區
= 07:00起理論上已在市區，但：
  - 住宿15:00才能check-in，中間有近8小時空窗
  - 旅客整夜未睡，體力低，即使時數長也不能排高強度行程
處理方式：
  1. 先至住宿或鄰近寄物櫃寄放大件行李
  2. 07:00-15:00這段「加長版上午」只排低強度、可隨時中斷的項目：早餐、室內歇腳、短程散步
  3. 15:00 check-in後才排下午真正行程，強度也要打折（旅客已醒10+小時）
  4. 標註：「Day1上午：落地整理＋輕量歇腳（低強度，勿排需預約項目）」
```
草稿原訂Day1排了景福宮＋北村＋益善洞＋東大門＋明洞的完整行程，**強度偏高**，三套方案皆會在此基礎上依各自邏輯做強度微調（尤其方案C）。

**Day5（10/21）離境：**
```
起飛時刻：16:10
- 建議提前抵達機場時數：2.5-3小時 → 最晚13:10前抵達機場
- 住宿到機場交通時間：約60-75分鐘 → 最晚12:00前需離開住宿
- 退房/收行李緩衝：30分鐘 → 最晚11:30前完成退房
= 早上醒來到11:30之間，扣除早餐與退房，末半天實際可用約3小時
處理方式：
  1. 只安排住宿步行圈內的行程（德壽宮步行可達）
  2. 不排需要往返交通或大包小包的體驗活動
  3. 機場貴賓室使用安排在證照查驗與安檢之後（見02通關）
  4. 標註：「Day5上午：住宿圈內輕量活動＋退房＋前往機場（實際可用約3小時，不排新景點）」
```
草稿原訂「10:30住宿大廳集合」比回推算出的12:00更早、更保守，屬合理安排，三套方案沿用此時間點。

## 方案 C｜輕鬆慢遊

**適合誰**：長輩同行、體力有限、不想趕行程的旅客（本次4位成人同行，草稿未排除含長輩之可能，故此方案特別強化低強度與室內歇腳密度）。選材邏輯：每天景點數減半、移動距離最短、`rainy_day_ok`／室內歇腳密度最高。

### Day1（10/17）落地日
- **上午（低強度）**：落地整理，早餐選住宿最近的咖啡廳，**不排景福宮等高強度項目**
- **下午（僅安排1-2個重點，非全部草稿項目）**：
  - 景點：**景福宮**（僅此一個古蹟重點，北村與益善洞留待精力較好的Day4補入或直接省略，以維持低密度）
  - Plan B：**國立古宮博物館**（`s_gogung_museum`，室內、有電梯、適合長輩）
  - 住宿辦理入住（提早結束當日行程，讓長輩早點休息）
- **晚間**：明洞範圍內找家庭式餐廳用餐，不特別排隊排長龍店家

### Day2（10/18）
- **上午**：鷺梁津水產市場（草稿指名保留，但只安排採買+用餐，不逛整個市場）
- **下午**：**THE HYUNDAI SEOUL**（`s_hyundai_seoul`，rainy_day_ok，室內、電梯手扶梯齊全、有育嬰室與充足座位，最適合長輩歇腳的半天安排，省略汝矣島漢江公園步行行程）
- **晚間**：早點回住宿休息，**63大廈夜景視體力狀況決定是否安排**（草稿原訂項目，方案C標記為彈性項目）

### Day3（10/19）南怡島包車一日遊（**未建檔，沿用草稿原文**——包車本身已是輕鬆選項，全程有車接送，體力負擔低於自由行走行程）

### Day4（10/20）
- **上午**：首爾林（`s_seoul_forest`，腹地大但步道平坦，有座位可讓長輩歇息，僅安排公園散步不排聖水洞逛街購物）
- **中午**：**소문난성수감자탕**（`f_somunnan_gamjatang`，湯頭清淡不辣，適合長輩口味，惟需留意排隊，建議避開尖峰）
- **下午**：**IPARI書齋**（`s_seongsu_cafe_st`區域內，`f_ipari_library`，rainy_day_ok，安靜室內歇腳）
- **18:00前**：移動至光化門站搭首爾觀光巴士夜遊（**未建檔，沿用草稿原文**——巴士本身即為坐著看夜景的低體力選項，適合方案C）

### Day5（10/21）離境日
- **上午**：住宿圈內散步，**德壽宮視體力狀況決定是否前往**（步行圈內、腹地小，適合輕量安排；若體力不足可改為住宿周邊咖啡廳休息至集合時間）
